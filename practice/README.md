# practice

学習中に作るRustプロジェクト・練習コードの置き場。

## 構成ルール

- 各サブディレクトリは **独立したCargoプロジェクト**（`cargo new` で初期化）
- **Cargo workspace は使わない**（学習用にシンプルに保つ）
- 1つの概念の練習で複数ファイルが必要な時は、`practice/{概念名}/` のサブディレクトリにまとめる

## 一覧

(まだプロジェクトはありません)

## 想定される命名

- フェーズ1: 概念ごとの練習用小プロジェクト（例: `hello-world/`, `ownership-practice/`）
- フェーズ2: `task-cli/`（タスク管理CLI）
- フェーズ3: 非同期処理の練習用コード（例: `async-practice/`）
- フェーズ4: `task-api/`（タスク管理 Web API）
