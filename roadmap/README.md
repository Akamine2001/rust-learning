# Rust学習ロードマップ

## 概要

Rustを基礎から学び、最終的にWeb APIを作れるようになることを目指す学習プロジェクト。

## 最終目標

タスク管理 Web API（axum + SQLite + JWT認証）を作り上げる。

| フェーズ | 内容 | 成果物 |

| 3 | 非同期処理（async/await） | - |
| 4 | Web API プロジェクト | タスク管理Web API（認証付き） |
