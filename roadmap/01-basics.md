# フェーズ1: Rust基礎構文

## ゴール

Rustの基本的な文法と概念を理解し、簡単なプログラムを書けるようになる。

## 学習トピック

### 1. プロジェクトの基本
- `cargo new` / `cargo run` / `cargo build`
- `Cargo.toml` の構造
- `println!` マクロ

### 2. 変数と型
- `let` と `let mut`（イミュータブル / ミュータブル）
- シャドーイング
- 基本型: 整数 / 浮動小数点 / 真偽値 / 文字
- `&str` と `String` の違い

### 3. 関数
- 関数定義（`fn`）
- 引数と戻り値
- 式と文の違い

### 4. 制御構文
- `if` / `else`（式として使える）
- `loop` / `while` / `for`
- `match`（パターンマッチ）

### 5. 標準入出力
- `std::io::stdin().read_line()`
- `trim()` で改行除去
- `parse::<T>()` で文字列→数値変換

### 6. 所有権（Rust最重要概念）
- 所有権のルール
- ムーブ（所有権の移動）
- 借用（`&` / `&mut`）
- 借用チェッカが何を見ているか（概要）
  - ※明示的なライフタイム注釈は本フェーズでは深掘りしない

### 7. データ構造
- 構造体（`struct`）
- 列挙型（`enum`）
- タプル
- 配列とスライス
- `Vec<T>` / `HashMap<K, V>`

### 8. メソッド構文
- `impl` ブロック
- `&self` / `&mut self` / `self`
- 関連関数（`Self::new()` のようなコンストラクタ的なもの）

### 9. パターンマッチ
- `match` の網羅性
- `if let` / `while let`

### 10. エラー処理
- `Option<T>` / `Result<T, E>`
- `?` 演算子
- `panic!`

### 11. モジュール
- `mod` と `use`
- ファイル分割

### 12. トレイト
- トレイトの概念（インターフェースのようなもの）
- `derive` 属性（`Debug`, `Clone`, `PartialEq` など）
- 自前トレイトの定義と実装

### 13. ジェネリクス（基礎）
- 関数のジェネリクス
- 構造体のジェネリクス

### 14. イテレータ（基礎）
- `iter()` / `into_iter()` / `iter_mut()`
- `map` / `filter` / `collect`

### 15. テスト基礎
- `#[test]` 属性
- `cargo test`
- `assert_eq!` / `assert!`

## このフェーズの終わり方

各トピックを理解した後、簡単な練習問題（FizzBuzz、文字列処理、簡易電卓）を解いて、フェーズ2に進む準備が整ったら次へ。
